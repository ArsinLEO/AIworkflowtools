============================================
  CenterCropTool - 居中裁切工具
============================================

【这个工具是干什么的？】
将一批 PNG 图片按居中方式裁切到目标尺寸。
裁掉四周多余的像素，保留中间部分。

举例：720x720 → 640x640，四边各裁掉 40px。


============================================
【目录结构】
============================================

CenterCropTool/
  input/                     <- 输入文件夹（丢整个文件夹进来）
  output/                    <- 输出文件夹（保持子目录结构）
  双击运行居中裁切.py        <- 双击运行脚本
  center_crop.py             <- 核心脚本
  README.txt                 <- 本说明文件


============================================
【使用步骤】
============================================

第1步：准备素材
  把包含 PNG 图片的整个文件夹丢入 input/。
  支持子文件夹，如：
    input/
      D20骰子动画/
        0.png
        1.png
        ...
      Boss特效/
        frame_001.png
        ...

第2步：运行裁切
  双击运行：双击运行居中裁切.py
  → 显示各子文件夹的文件数量和参考尺寸
  → 输入目标尺寸（如 640 或 640x480）
  → 确认后自动裁切

第3步：取走结果
  结果输出到 output/ 文件夹，保持原始子目录结构：
    output/
      D20骰子动画/
        0.png (640x640)
        ...


============================================
【注意事项】
============================================

1. 依赖 Python 3 + Pillow：
     pip install Pillow

2. 裁切是居中裁切，四边均匀裁掉。

3. 只处理 .png 文件，递归搜索所有子文件夹。

4. 如果原图小于目标尺寸，会跳过该文件。

5. 输出保持原始文件名和子目录结构。
