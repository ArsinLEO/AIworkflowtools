============================================
  SpriteSheetTool - 序列帧图集生成工具
============================================

【这个工具是干什么的？】
将多组PNG序列帧按固定列数排列，组合成一张大图（Sprite Sheet）。

支持特性：
  - 每行固定4帧（可修改脚本顶部 COLS 参数）
  - 按文件名字母顺序排列
  - 帧尺寸不一致时自动居中放置
  - 透明背景保留
  - 支持子文件夹批量处理


============================================
【目录结构】
============================================

SpriteSheetTool/
  input/                  <- 输入文件夹（放PNG序列帧）
  output/                 <- 输出文件夹（生成的大图）
  双击运行生成图集.py     <- 双击运行脚本
  auto_generate_spritesheet.py  <- 核心脚本
  README.txt              <- 本说明文件


============================================
【使用步骤】
============================================

第1步：准备序列帧
  把PNG序列帧放入 input/ 文件夹。

  支持两种放置方式：
    - 直接放PNG到 input/ 根目录 → 生成 spritesheet.png
    - 或创建子文件夹（如 input/攻击/、input/防御/），
      每个子文件夹生成一张独立的图集，文件名即子文件夹名

第2步：运行生成
  双击运行：双击运行生成图集.py
  脚本会自动排列并输出大图。

第3步：取走结果
  结果输出到 output/ 文件夹。


============================================
【高级配置（可选）】
============================================

打开 auto_generate_spritesheet.py，修改顶部配置：

  COLS = 4
    每行排列的帧数。改为 8 则每行8帧。


============================================
【注意事项】
============================================

1. 本工具依赖 Python 3 和 Pillow 库。
   如果双击运行报错，可能需要安装：
     pip install Pillow

2. 每次使用前，建议先清空 output/ 文件夹
   里的旧文件，避免新旧文件混在一起。

3. 如果序列帧尺寸不一致，工具会自动取
   最大宽高作为单元格尺寸，小帧居中放置。

4. 大图背景为透明（alpha=0），可直接用于
   游戏引擎的 Sprite Sheet 导入。
