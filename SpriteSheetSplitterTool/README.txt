============================================
  SpriteSheetSplitterTool - 精灵图集拆分工具
============================================

【这个工具是干什么的？】
将 Sprite Sheet（精灵图集 / 雪碧图）按指定行列数拆回单个帧 PNG。
是 SpriteSheetTool 的反向操作。

工作原理：
  全图均匀切分 → cell_w = 图宽÷列数, cell_h = 图高÷行数
  → 所有输出帧尺寸完全一致 → 自动跳过全透明空帧


============================================
【目录结构】
============================================

SpriteSheetSplitterTool/
  input/                     <- 输入文件夹（放 Sprite Sheet PNG）
  output/                    <- 输出文件夹（拆分后的单帧）
  双击运行拆分图集.py        <- 双击运行脚本
  auto_split_spritesheet.py  <- 核心脚本
  README.txt                 <- 本说明文件


============================================
【使用步骤】
============================================

第1步：准备图集
  把需要拆分的 Sprite Sheet PNG 放入 input/ 文件夹。
  支持子文件夹（如 input/攻击/），按子文件夹分组输出。

第2步：运行拆分
  双击运行：双击运行拆分图集.py
  → 脚本列出所有找到的图集及其尺寸
  → 输入列数（比如 4）
  → 输入行数（比如 2）
  → 自动拆分

第3步：取走结果
  结果输出到 output/ 文件夹，每张图集一个同名子文件夹：
    input/攻击.png  →  output/攻击/0.png, 1.png, 2.png ...
    input/防御.png  →  output/防御/0.png, 1.png, 2.png ...
  所有帧尺寸统一。


============================================
【与 SpriteSheetTool 配合】
============================================

SpriteSheetTool 生成 4列 的图集 → 本工具输入 cols=4, rows=?
举例：
  30帧序列，SpriteSheetTool 4列 → 图集 col=4, row=8
  在本工具中输入 cols=4, rows=8 即可无损拆回 30 帧


============================================
【注意事项】
============================================

1. 依赖 Python 3 + Pillow：
     pip install Pillow

2. 所有输出帧大小一致（cell_w × cell_h），
   帧在单元格中保持原始位置（含透明留白）。

3. 全透明的空单元格自动跳过，不输出。

4. 如果拆分出来的帧数不对，检查行列数是否正确。
   行数 = ceil(总帧数 / 列数)
