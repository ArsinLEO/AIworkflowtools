============================================
  VideoToSpriteSheetTool - 视频转精灵图集工具
============================================

【这个工具是干什么的？】
将 MP4 视频按指定帧率提取帧画面，组合成 Godot 可用的精灵图集。

支持特性：
  - 按目标帧率（默认12FPS）从视频中均匀提取帧
  - 保持原始帧尺寸，不做任何缩放或压缩
  - 自动计算最优网格布局（4列起步，自适应调整）
  - 遵守 Godot 纹理上限（8192px），超出自动分割为多张图集
  - 支持子文件夹批量处理
  - 输出透明背景 PNG 图集


============================================
【目录结构】
============================================

VideoToSpriteSheetTool/
  input/                          <- 输入文件夹（放MP4视频）
  output/                         <- 输出文件夹（精灵图集PNG）
  frames/                         <- 提取的原始单帧（按视频名存放子文件夹）
  双击运行视频转图集.py            <- 双击运行脚本
  auto_video_to_spritesheet.py    <- 核心脚本
  README.txt                      <- 本说明文件


============================================
【使用步骤】
============================================

第1步：放入视频
  把 MP4 视频文件放入 input/ 文件夹。

  支持两种放置方式：
    - 直接放视频到 input/ 根目录 → 为每个视频生成图集
    - 或创建子文件夹（如 input/角色A/、input/技能B/），
      每个子文件夹内的视频分别处理，图集名即视频文件名

第2步：运行转换
  双击运行：双击运行视频转图集.py
  脚本会自动提取帧并合成图集。

第3步：取走结果
  - 精灵图集 → output/ 文件夹（可直接导入 Godot）
  - 原始单帧 → frames/<视频名>/ 文件夹（备用）


============================================
【高级配置（可选）】
============================================

打开 auto_video_to_spritesheet.py，修改顶部配置：

  TARGET_FPS = 12
    目标提取帧率。改为 24 则每秒提取24帧。

  COLS = 4
    每行排列的帧数偏好值。实际值会根据纹理限制自动调整。

  MAX_TEXTURE_SIZE = 8192
    Godot 纹理尺寸上限。
    - 8192 = 主流 GPU 安全值（默认）
    - 16384 = 高端 GPU（RTX 30系及以上）


============================================
【工作流配合】
============================================

本工具输出的精灵图集可以用 SpriteSheetSplitterTool 拆分回单帧。

完整流程：
  视频 → [本工具] → 精灵图集 → [SpriteSheetSplitterTool] → 单帧PNG


============================================
【Godot 导入提示】
============================================

1. 将图集 PNG 拖入 Godot 项目
2. 在导入面板设置 Texture 类型为 2D
3. 创建一个 Sprite2D / AnimatedSprite2D
4. 使用 AnimationPlayer 或代码按帧播放

对于 AnimatedSprite2D：
  - 设置 Hframes = 列数, Vframes = 行数
  - 帧索引从左到右、从上到下排列

【依赖要求】
============================================

（Pillow 通常已安装）
