============================================
  RemoveWatermarkTool - 序列帧去水印工具
============================================

【这个工具是干什么的？】
自动检测并去除PNG序列帧四个角落的水印（左上、右上、左下、右下）。
专为"豆包AI生成"类文字水印设计，也支持其他形状和颜色的水印。

支持的水印特征：
  - 位置：四个角落任意位置
  - 颜色：任意颜色（不依赖颜色识别）
  - 形状：文字、图标、logo 等任意形状
  - 透明度：支持半透明水印
  - 动态出现：同一序列中水印可在不同时段出现在不同角落

核心原理（四步逼近法 + 壳层精修）：
  1. 全画面连通组件分析（大范围搜索）
  2. 排除最大组件（人物主体），只保留孤立组件
  3. 四个角落分别收集组件边界框，取最大横向跨度
  4. 中位数行高矩形粗删主体
  5. 5轮壳层精修（2轮3像素 + 3轮1像素）清除边缘残留


============================================
【目录结构】
============================================

RemoveWatermarkTool/
  input/                  <-- 输入文件夹（放PNG序列帧）
  output/                 <-- 输出文件夹
  双击运行去水印.py       <-- 双击运行脚本
  auto_remove_watermark.py  <-- 核心脚本
  README.txt              <-- 本说明文件


============================================
【使用步骤】
============================================

第1步：准备序列帧
  把需要去水印的PNG序列帧放入 input/ 文件夹。

  支持两种放置方式：
    - 直接放PNG到 input/ 根目录
    - 或创建子文件夹（如 input/攻击/、input/防御/），
      每个子文件夹放一组序列帧

  提示：放入多张序列帧（同一动作的连续帧）
  可以获得最准确的检测效果。单张图也能处理，
  但精度会降低。

  重要：请先人工筛选，确保水印不会与人物主体严重重叠。
  如果水印与人物重叠，工具可能会误删人物边缘。

第2步：运行去水印
  双击运行：双击运行去水印.py
  脚本会自动分析并输出去除水印后的图片。

第3步：检查结果
  结果输出到 output/ 文件夹。
  如果效果不理想，可以尝试：
    - 放入更多序列帧提高检测精度
    - 调整 auto_remove_watermark.py 中的参数
      （见下方"高级配置"）


============================================
【高级配置（可选）】
============================================

打开 auto_remove_watermark.py，修改顶部配置：

  CORNER_W = 0.40
    左右两侧检测宽度占画面的比例（0~1）
    如果水印很宽，可以调大这个值。

  CORNER_H = 0.35
    上/下检测高度占画面的比例（0~1）
    如果水印很高，可以调大这个值。

  MIN_WATERMARK_SIZE = 20
    最小水印组件面积（像素数）。
    小于此值的噪点会被忽略。

  MAX_WATERMARK_SIZE = 5000
    最大水印组件面积（像素数）。
    大于此值的会被认为是人物碎片而排除。

  MAX_COMPONENT_DENSITY = 0.85
    组件密度阈值。文字水印密度低（笔画有间隙），
    人物碎片密度高。如果文字水印被漏检，可以调大。

  MIN_ASPECT_RATIO = 2.0
    水印宽高比阈值（宽/高）。
    横向文字水印宽明显大于高。

  MAX_DELETE_RATIO = 0.20
    删除安全阀：最多删除画面20%的像素。
    超过则自动放弃，避免大面积误删。

  PROCESS_SCALE = 0.25
    内部处理时的缩放比例。
    越小处理越快，但精度越低。
    通常 0.25~0.5 之间即可。


============================================
【注意事项】
============================================

1. 本工具依赖 Python 3 和 Pillow 库。
   如果双击运行报错，可能需要安装：
     pip install Pillow

2. 每次使用前，建议先清空 output/ 文件夹
   里的旧文件，避免新旧文件混在一起。

3. 水印去除后，原区域会变为透明（alpha=0）。
   如果你的游戏引擎不支持透明背景，
   需要额外添加背景层。

4. 如果水印与人物有严重重叠，
   去除时可能会影响人物边缘。
   这种情况建议手动修复或使用更专业的
   图像修复工具（如 Photoshop 的内容识别填充）。

5. 工具使用两步删除策略：
   - 第一步：矩形粗删（中位数行高 + 10%扩展）
   - 第二步：5轮壳层精修（逐步清除边缘残留）
   壳层精修有安全限制：删除量不超过第一步的20%


============================================
【技术原理】
============================================

四步逼近法：
  1. 全画面连通组件分析：检测所有非透明区域
  2. 排除最大组件（人物主体）：水印是孤立的小组件
  3. 多角落锁定：每个有水印的角落都生成删除区域
  4. 精确矩形删除：横向取最大宽度，纵向取中位数行高

壳层精修：
  - 第1-2轮：在矩形边界外搜索距离<=3像素的残留
  - 第3-5轮：在更新后的边界外搜索距离<=1像素的残留
  - 每轮排除最大组件（防止误删人物边缘）
  - 总精修删除量不超过第一步的20%
