============================================
  ResizeAndLocalTool - 序列帧对齐工具
============================================

【这个工具是干什么的？】
当你有多组角色动画序列帧（比如：攻击、防御、待机、技能等），
它们的画布尺寸、人物大小、人物位置都不一样。
这个工具可以把所有序列帧统一到同一个标准：

  - 画布统一为参考图的尺寸
  - 人物（实体A）的大小和位置与参考图一致
  - 文件名重命名为 0.png, 1.png, 2.png ...

这样所有动画序列就可以在游戏引擎中直接替换使用，
不会出现人物忽大忽小、位置偏移的问题。


============================================
【目录结构】
============================================

ResizeAndLocalTool/
  reference/            <- 放1张标准参考图（仅1张PNG）
  input/                <- 放多个子文件夹，每个是一组序列帧
  output/               <- 输出结果（脚本自动生成）
  1. 双击运行预览.py    <- 第一步：生成预览图和参数
  2. 双击执行全部.py    <- 第二步：应用到全部帧并输出
  square_to_target.py   <- 独立工具：方形化 + 缩放到指定尺寸
  双击方形化缩放.py     <- 双击启动方形化工具


============================================
【使用步骤】
============================================

第1步：准备参考图
  把一张你希望作为标准的图（如红色法阵第一帧）
  放入 reference/ 文件夹，确保只有1张PNG。

第2步：准备输入文件夹
  在 input/ 文件夹下创建多个子文件夹，
  每个子文件夹放一组序列帧PNG图。

第3步：生成预览
  双击运行：1. 双击运行预览.py
  预览图生成到 output/_preview/，检查对齐效果。

第4步：执行全部
  确认预览无误后，
  双击运行：2. 双击执行全部.py
  输出最终结果到 output/ 文件夹，画布尺寸与参考图一致。

第5步（可选）：方形化缩放
  如果需要在游戏引擎中使用统一正方形尺寸，
  把 output/ 中的帧放入本工具的 input/，
  双击运行：双击方形化缩放.py
  输入目标尺寸（如 640），即可扩展为正方形并缩放。


============================================
【方形化缩放工具】
============================================

独立工具 square_to_target.py：
  - 将任意尺寸PNG扩展为正方形（居中，不拉伸）
  - 缩放到指定尺寸（默认 640x640）
  - 支持子文件夹批量处理

用法：
  1. 把PNG放入 input/
  2. 双击 双击方形化缩放.py
  3. 输入目标尺寸（回车默认640）
  4. 结果输出到 output/


============================================
【注意事项】
============================================

1. 依赖 Python 3 + Pillow：
     pip install Pillow

2. 每次使用前，建议先清空 output/ 文件夹。

3. 参考图只能放1张PNG。

4. 如果某组序列帧检测不到实体A（全是透明），
   脚本会跳过该文件夹并提示警告。
