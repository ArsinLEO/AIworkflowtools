============================================
  ResizeAndLocalTool - 序列帧对齐工具
============================================

【这个工具是干什么的？】
当你有多组角色动画序列帧（比如：攻击、防御、待机、技能等），
它们的画布尺寸、人物大小、人物位置都不一样。
这个工具可以把所有序列帧统一到同一个标准：

  - 画布统一为参考图的尺寸
  - 人物（实体A）的大小和位置与参考图一致
  - 最终扩展为正方形，缩放到 640x640
  - 文件名重命名为 0.png, 1.png, 2.png ...

这样所有动画序列就可以在游戏引擎中直接替换使用，
不会出现人物忽大忽小、位置偏移的问题。


============================================
【目录结构】
============================================

ResizeAndLocalTool/
  reference/          <- 放1张标准参考图（仅1张PNG）
  input/              <- 放多个子文件夹，每个是一组序列帧
  output/             <- 输出结果（脚本自动生成）
  1. 双击运行预览.py  <- 第一步：生成预览图和参数
  2. 双击执行全部.py  <- 第二步：应用到全部帧并输出


============================================
【使用步骤】
============================================

第1步：准备参考图
  把一张你希望作为标准的图（如红色法阵第一帧）
  放入 reference/ 文件夹，确保只有1张PNG。

第2步：准备输入文件夹
  在 input/ 文件夹下创建多个子文件夹，
  每个子文件夹放一组序列帧PNG图。
  子文件夹名字可以任意（如"攻击"、"防御"等）。

第3步：生成预览
  双击运行：1. 双击运行预览.py
  脚本会自动分析参考图和每组序列帧的第一帧，
  计算缩放比例和偏移量，并在 output/_preview/ 生成预览图。

第4步：检查预览
  打开 output/_preview/ 文件夹，
  检查每组预览图的人物是否与参考图对齐。
  如果对齐效果不满意，换一张参考图重新运行第3步。

第5步：执行全部
  确认预览无误后，
  双击运行：2. 双击执行全部.py
  脚本会把对齐参数应用到每组序列帧的每一张图，
  输出最终结果到 output/ 文件夹。

第6步：取走结果
  output/ 下每个子文件夹就是最终输出，
  文件名已重命名为 0.png, 1.png, 2.png ...，
  尺寸统一为 640x640。


============================================
【注意事项】
============================================

1. 每次使用前，建议先清空 output/ 文件夹里的旧文件，
   避免新旧文件混在一起。

2. 参考图只能放1张PNG，放多了会用第一张。

3. input/ 下的子文件夹里只能放PNG格式的序列帧图，
   其他格式会被忽略。

4. 如果某组序列帧检测不到实体A（全是透明），
   脚本会跳过该文件夹并提示警告。

5. 本工具依赖 Python 3 和 Pillow 库（PIL）。
   如果双击运行报错，可能需要安装：
     pip install Pillow


============================================
【技术原理】
============================================

- 实体A检测：使用最大连通组件算法，
  排除分离的光晕/噪点，只取人物主体区域。

- 对齐方式：保持宽高比，以高度为基准计算缩放比例，
  然后将人物主体边界框对齐到参考图的位置。

- 同一组序列帧使用相同的缩放和偏移参数，
  确保动画连贯性不会崩。
