============================================
  ColorMatchTool - 色彩匹配调色工具
============================================

【这个工具是干什么的？】
将一批图片的色彩，匹配到参考图片的色调。
支持两种模式，自动识别。

LUT 模式（精确）：
  适用于参考图和输入图是"同一帧不同调色"的场景。
  从像素对中提取精确的 RGB 曲线，逐通道映射。
  → 需要 reference/ 和 input/ 中有一张同尺寸的图。

LAB 迁移模式（通用）：
  适用于参考图和输入图是不同内容的场景。
  在 LAB 色彩空间匹配均值和标准差。
  → 任何图片都能匹配，但精度不如 LUT。

举例：
  reference/3333.png（暖色版本）
  input/0.png         （冷色版本，与 3333 同尺寸）
  → LUT 模式：提取 0→3333 的曲线，应用到所有 input


============================================
【目录结构】
============================================

ColorMatchTool/
  reference/                 <- 参考图（目标色调）
  input/                     <- 需要调色的图片（支持子文件夹）
  output/                    <- 调色后的输出
  双击运行色彩匹配.py        <- 双击运行
  color_match.py             <- 核心脚本
  README.txt                 <- 本说明


============================================
【使用步骤】
============================================

第1步：放入参考图
  把目标色调的图片放入 reference/ 文件夹。
  通常放 1 张即可。

第2步：放入待处理图片
  把需要调色的图片放入 input/ 文件夹。
  支持子文件夹，输出保持目录结构。

第3步：运行
  双击运行：双击运行色彩匹配.py
  → 显示 reference 和 input 的文件摘要
  → 自动选择 LUT 或 LAB 模式并说明原因
  → 确认后开始处理

第4步：取走结果
  结果在 output/ 文件夹，保持原始目录结构。


============================================
【最佳实践】
============================================

1. 如果有同内容的"前/后"对比图：
   → 把"后"（目标色调）放 reference/
   → 把"前"（原始色调）放 input/（和其他待处理图一起）
   → 工具自动检测到同尺寸图，启用 LUT 模式
   → 颜色匹配精度最高

2. 如果只是想套用某种色调风格：
   → 把风格参考图放 reference/
   → input/ 放入需要套用的图
   → 工具使用 LAB 迁移模式


============================================
【注意事项】
============================================

1. 依赖 Python 3 + Pillow + numpy + scipy：
     pip install Pillow numpy scipy

2. LUT 模式要求参考图和输入中有一张尺寸完全相同。

3. 只处理 .png 文件，递归搜索所有子文件夹。

4. 输出保持原始文件名和子目录结构。
